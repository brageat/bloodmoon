How it fits together

BepInEx

PEAK\BepInEx\

Loads Bloodmoon.dll when the game starts.

Plugin

Plugin.cs

Lists the modules, watches Insert, runs each module every frame and physics step, saves settings and logs errors.

Modules

Modules/*.cs

Each mod adds its rows in Init() and does its work in Tick() / FixedTick().

SpeedClimbFlyStaminaHealthTeleportItemsStopFog

Menu

Menu/*.cs

Draws the rows by type (slider, toggle, button), fits as many as there's room for, handles the keys and holds the theme.
